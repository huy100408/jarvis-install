How to install JARVIS on a Mac

JARVIS is an AI assistant that sees your screen, moves the cursor, runs tools and answers out loud. Installing it on a Mac takes about two minutes, and you don't need an API key.

1. Check that your Mac is supported

JARVIS runs only on Macs with an Apple M-series chip. The installer stops if it detects an Intel Mac. Open Terminal and run:

uname -m

If it prints arm64, you're good.

2. Install JARVIS

Option A: the DMG installer (easiest)

  1. Download Jarvis.dmg.
  2. Open it and drag Jarvis into Applications.
  3. Open Jarvis from Applications or Launchpad.

Option B: one Terminal command

Paste this into Terminal. It installs everything, starts the background services and opens Jarvis.app:

curl -fsSL https://huy100408.github.io/jarvis-install/install.sh | bash

If Python 3.12 or Node.js is missing, the installer adds them with Homebrew. If you don't have Homebrew, install it first from brew.sh. Every download is checked against its sha256 before it is installed.

3. Grant Screen Recording and Accessibility

JARVIS needs to see the screen and control the mouse and keyboard. When macOS asks, open System Settings → Privacy & Security and turn Jarvis on under both:

  • Screen Recording
  • Accessibility

You can jump straight to each panel from Terminal:

open "x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture"
open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"

4. Sign in and give it a task

  1. Sign in with Google. The free plan includes 5 cloud messages a day, 30 a month.
  2. Type or push to talk, for example: “Open Safari and find the latest version of Expo.”
  3. JARVIS reads the screen, makes one move, checks the result, then continues.

Passwords, payments, keychain access and destructive commands always pause JARVIS and ask you first.

Optional: control your Mac from your iPhone

Sideload Jarvis.ipa with AltStore, SideStore or Sideloadly. Your phone and Mac need to be on the same network or Tailscale. In the app, enter your Mac's IP with port 20129. To find the IP:

ipconfig getifaddr en0

Update or uninstall

jarvis update
jarvis uninstall

The uninstaller lists everything first and asks before removing anything. Add --keep-data to keep your settings.
