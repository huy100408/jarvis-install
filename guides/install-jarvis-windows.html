How to install JARVIS on Windows 10 and 11

JARVIS is an AI assistant for your PC that answers out loud, searches the web and asks before any sensitive action. It installs for your user account in about two minutes, with no administrator rights and no API key.

Option A: the setup program (easiest)

  1. Download Jarvis-Setup.exe.
  2. Double-click it.
  3. If Windows shows “Windows protected your PC”, choose More info, then Run anyway.
  4. Follow the steps. Jarvis appears in the Start Menu and on your desktop.

Option B: one PowerShell command

Open PowerShell and paste:

irm https://huy100408.github.io/jarvis-install/install.ps1 | iex

It adds Python 3.12 if needed and installs Jarvis for your account. Prefer double-clicking? Install-Jarvis.cmd does the same thing.

Sign in and start chatting

  1. Open Jarvis. It runs in its own window.
  2. Sign in with Google. The free plan includes 5 cloud messages a day, 30 a month. Pro is unlimited.
  3. Want to use your own AI provider? Add your key in Settings.

Jarvis asks before any sensitive action, such as passwords, payments or destructive commands.

Update or uninstall

jarvis update
jarvis uninstall

You can also remove it from Settings → Apps → Jarvis → Uninstall. Add -KeepData to the uninstall command to keep your settings. Without the jarvis command:

irm https://huy100408.github.io/jarvis-install/uninstall.ps1 | iex
